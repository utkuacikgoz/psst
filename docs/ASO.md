# App Store search (ASO)

Paste into App Store Connect → Psst → App Information (name, subtitle) and the version page (promotional text, description, keywords, What's New). Name and subtitle changes go out with the next version you submit; promotional text can change any time. Character counts are checked.

Rules Apple applies: the name, subtitle and keywords are all searched together, so a word is never repeated across them. Keywords are comma-separated with no spaces. Apple combines words across fields, so "miss" + "you" still matches "miss you".
